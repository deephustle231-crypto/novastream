# NovaStream Project Directives & Rules

## 1. Permanent Application Name
- The name of this application is **NovaStream** (or **Nova Stream**).
- **CRITICAL DIRECTIVE**: You must **NEVER** change, alter, prefix, suffix, or replace the name of this app under any circumstances. It must always remain **NovaStream**.
- All titles in `metadata.json`, `index.html`, `Navbar.tsx`, `Footer.tsx`, and all UI components must consistently maintain the **NovaStream** branding.

## 2. Interface Architecture & Design System
- The interface must remain strictly identical to the **Netflix** web and streaming application design:
  - **Color Palette**: Dark cinema canvas (`#141414`), card surfaces (`#181818`), and signature Netflix red accents (`#E50914`).
  - **Cinematic Billboard Hero**: High-impact full-width backdrop with multi-directional dark gradients, `N` NOVA ORIGINAL badge, large white Play button, translucent More Info button, maturity rating tag, and audio controls.
  - **Netflix Media Rows**: Horizontal carousels with smooth chevron scrolling for categories like Trending Now, Sci-Fi & Action, Noir & Suspense, Animation, and TV Series.
  - **Top 10 Masterworks Row**: Distinctive oversized 3D stroke outline numbers (1 through 10) flanking tall vertical poster cards.
  - **Interactive Hover Cards**: Quick action controls (Play, Add to List, Like, Details), green match percentage (`98% Match`), maturity rating, duration, and bulleted genre lists.
  - **Cinematic Video Player**: Multi-server mirror switching (`S1`, `S2`), resolution quality picker (`1080p`, `720p`), progress tracking, and cinema controls.
